# 우리교회 배경 메이커

예배·찬양 자막 뒤에 깔 **끊김 없는 루프 배경 영상(MP4)** 과 정지 배경(PNG)을
설치·로그인 없이 브라우저에서 만드는 교회 내부용 무료 도구.

- 사이트: https://ciscons.github.io/church-bg/
- 저장소: https://github.com/ciscons/church-bg
- 현재 버전: **v0.3**
- 상태: 정식 운영 (MVP 단계 종료)

---

## 1. 배경과 목적

- 매주 PPT·FreeShow 배경을 찾아 헤매는 방송실 봉사자의 시간을 줄인다.
- 외부 유료 라이브러리(Sunday Screens 등) 없이 교회 톤에 맞는 배경을 무한 생성한다.
- FreeShow에서 배경 루프가 "뚝" 끊기던 문제를 **수학적 완벽 루프**로 해결한다.
- 운영비 0원: 서버·DB·회원가입 없음. 모든 렌더링·인코딩은 사용자 PC에서.

참고한 서비스
- LEEGANSA STUDIO (leegansa.com/studio): 브라우저 루프 배경 생성기 구조·UX 참고
- Sunday Screens (sundayscreens.com): 테마 패밀리·다이나믹 레이어 개념 참고

## 2. 주요 기능 (v0.3)

### 테마 12종
| # | 테마 | 용도 |
|---|------|------|
| 0 | 그라데이션 | 느린 곡·기도 |
| 1 | 빛줄기 | 범용 (고깔형 볼류메트릭) |
| 2 | 입자·별 | 범용 |
| 3 | 불씨 | 성령강림·열정 |
| 4 | 눈 | 성탄·겨울 |
| 5 | 물결 | 세례·생수 |
| 6 | 구름 | 느린 곡·묵상 |
| 7 | 빛의 고리 | 빠른 곡 |
| 8 | 빛 상자 | 빠른 곡·청년부 |
| 9 | 모션 라인 | 빠른 곡·청년부 |
| 10 | 십자가 | 고난주간·성찬 |
| 11 | 스테인드글라스 | 절기·전통 |

### 다이나믹 S1~S5
같은 룩(색·구도·광원)을 유지한 채 움직임 강도만 5단계. 벌스→코러스 전환용.
S1~S5 세트 일괄 저장 지원.

### 조정
- 색상 3개(주·강조·바닥) + 팔레트 8종 + 랜덤 섞기
- 가사용 가운데 어둡게 (자막 가독성)
- 밝기
- 십자가 오버레이 (모든 테마 위에 실루엣+역광)
- 가사 미리보기 (샘플 자막 2줄)

### 프리셋
- 이름 붙여 저장 / 불러오기 / 삭제 (브라우저 localStorage)
- 시드 표시 → 동일 룩 재현 가능

### 출력
- MP4 (H.264): 720p / 1080p / 4K / 울트라와이드 3840×1280
- 24·30fps, 길이 10·20·30·60초, 화질 3단계
- PNG 스틸
- 진행률 표시, 취소, 백그라운드 탭에서도 인코딩 지속
- 파일명 자동: `배경_테마_S단계_길이_해상도_s시드.mp4`

## 3. 기술 구조

- **단일 파일** `index.html` (HTML + CSS + JS + GLSL)
- 렌더링: **WebGL2** 풀스크린 프래그먼트 셰이더
- 인코딩: **WebCodecs VideoEncoder** + `mp4-muxer`(jsDelivr CDN)
- 저장소: localStorage (프리셋)
- 호스팅: GitHub Pages (정적). Netlify에서 이전함 (크레딧 소진)

### 완벽 루프 원리
- 시간 `u_t`를 0→1 위상으로 전달. 모든 주기 함수는 `sin(2π·u_t·정수)`.
- 스크롤형 요소(입자)는 셀 단위 이동량을 정수로, 필드를 주기 P(레이어별 5/7/9)로 반복.
- 60초 출력 시 위상에 정수 배(2)를 곱해 체감 속도를 30초와 동일하게 유지.
- 결과: 마지막 프레임 = 첫 프레임이 수학적으로 일치. 플레이어 루프 재시작 외 끊김 없음.

### 셰이더 주의사항 (적용 완료)
- `pow()`에 음수 입력 금지 → `q*q` 사용
- `smoothstep(e0,e1,x)`는 e0<e1 필수 → 반전은 `1.-smoothstep()`
- 어두운 그라데이션 밴딩 방지용 1.5/255 디더 노이즈
- sin 기반 hash → 정밀도 높은 fract/dot hash로 교체

## 4. 사용법 (방송실)

1. PC Chrome/Edge로 사이트 접속 (폰은 미리보기만 가능)
2. 테마 → 다이나믹 단계 → 색상 선택
3. 가사용 어둡게 조절 후 "가사 미리보기"로 가독성 확인
4. `1080p · 30초 · 30fps · 고화질` 로 "영상 저장" 또는 "S1~S5 세트 저장"
5. FreeShow Media 폴더에 복사 → 슬라이드로 드래그 → 루프 켜기
6. 끊김이 느껴지면 60초 길이로 다시 저장

## 6. 테스트 방법

채팅 내 자동 테스트 위젯(동일 셰이더 코드)으로 검증:
- 컴파일 성공 여부
- 루프 이음새: t=0 vs t=1 평균 픽셀 차 < 12 (S1/S3/S5)
- 움직임: t=0 vs t=0.37 차이가 이음새의 1.5배 초과
- 밝기 5~60%, 검은 픽셀 < 90%
- 울트라와이드 3:1 렌더링 검정 여부
- 테마별 상대 연산 부하(ms)

실기 테스트(PC)
- 12테마 표시 / 720p·10초 저장 → FreeShow 루프 확인 / 프리셋 저장 후 새로고침 복원 / 세트 저장 중 취소

## 7. 알려진 이슈·확인 필요

- 폰 브라우저에서 미리보기 캔버스가 검게 보일 수 있음 (GPU/WebGL2 제한) — 폰은 지원 대상 아님
- 10·20초 루프는 30초 대비 움직임이 빠름 (테스트용)
- 테마별 세부 파라미터(빔 개수, 입자 수, 흐름 방향 등) 미노출 — v0.4 예정
- 4K 인코딩은 PC 성능 따라 수 분 소요
